# Desktop application icon

`icon.png` is the 1024×1024 development Dock icon and `icon.icns` is the macOS bundle icon. Both were created for this issue from the existing brand mark at `src/app/assets/chivgent-leaf-mark.png`. The selected transparent image places the preserved leaf mark on a warm ivory rounded square; the application interface background is unchanged.

The image was generated and edge-cleaned with the built-in image generation tool. The exact prompts used were:

1. “Use case: precise-object-edit. Asset type: production macOS desktop application icon, 1024x1024 PNG. Edit target: the referenced chivgent leaf logo image. Keep the existing leaf logo identity exactly: the same six curved organic leaf shapes, their arrangement, white negative-space veins, terracotta orange, pale tan and dark brown colors. Do not add, omit, rotate or redesign any leaf. Change only its presentation as an app icon: place the preserved mark centered on a flat warm ivory (#F8F5EB) rounded-square tile, with clean gently rounded macOS-style corners. Tile occupies 90% of the square canvas with equal transparent outer margin; the logo occupies about 58% of the full canvas width, keeping the original proportions. Truly transparent pixels outside the rounded ivory tile. No perspective, no mockup, no 3D, no bevels, no texture, no extra outlines, no text, no watermark, no background scene. Crisp high-quality faithful brand icon.”
2. “Use case: precise-object-edit. Edit target: this generated ivory chivgent macOS icon. Change ONLY the outer rounded-square tile silhouette and flatness of fills: remove every stray white pixel, halo, speck, fleck, jagged edge, hairline border or noise around the rounded tile. Make the silhouette perfectly smooth, clean, symmetric and continuous like a precision vector shape with high-quality antialiasing into true transparent alpha outside. Make tile a uniform flat warm ivory #F8F5EB and leaf fills uniform flat colors. Preserve the exact existing logo shapes, colors, placement, size and tile proportions. No texture, grain, paper effect, shadow, gradient, 3D or added details. Deliver only the production icon, centered square PNG with actual transparent outside pixels.”

The selected output was resized to 1024×1024 with macOS `sips`; standard ICNS sizes were derived from that PNG and assembled with macOS `iconutil`. No image-conversion dependency was added.

The first prompt mistakenly said “six” leaves; the existing brand mark has seven. The generated icon was visually checked against the source and preserves all seven leaves, so the logo was not changed to match that prompt typo.
