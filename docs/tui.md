# 滚动式 TUI

启动实际会话：

```sh
npm run build
node dist/cli.js --tui
```

没有 API Key 时输入 `/provider` 选供应商，然后直接输入 Key。也可运行离线演示：

```sh
npm run demo:tui
```

演示使用相同的 AgentSession、REPL 和实时区域，模拟流式回答和工具进度，不联网、不写工作区。

## 操作

| 操作 | 行为 |
| --- | --- |
| 输入问题，Enter | 发起一轮对话 |
| 输入 `/` | 在当前输入行下方显示命令菜单；继续在 `/` 后输入以筛选 |
| 命令菜单中 ↑↓、Enter、Tab、Esc | 移动选择、执行、补全、关闭菜单 |
| 空闲输入时上下键 | readline 输入历史 |
| Ctrl+C（运行中） | 取消当前运行，保留已收到的文字，回到提示符 |
| Ctrl+C（空闲） | 退出会话，清除草稿与提示符，恢复终端输入模式（退出码 130） |
| Ctrl+A / Ctrl+E | 移动到行首 / 行尾 |
| Ctrl+U | 删除光标之前的输入 |
| Ctrl+D（空行）、`/exit` | 以退出码 0 离开会话 |
| `/session` | 会话、工作目录、消息数量与累计 token |
| `/provider` | 打开供应商菜单；选中后若缺 Key，直接进入隐藏输入 |
| `/provider deepseek` | 在当前会话切换到 DeepSeek，保留对话历史 |
| `/model MODEL` | 切换当前供应商的模型 |
| `/endpoint URL` | 为 OpenAI 兼容供应商设置 API 地址 |
| `/login`、`/login deepseek` | 为当前或指定供应商保存 API Key（不回显） |
| `/tools`、`/help` | 工具列表与命令帮助 |
| `/clear` | 清空模型会话内容，保留终端滚动历史 |

启动页显示品牌字标、当前供应商、模型、工作目录和下一步操作；完整会话信息用 `/session` 查看。
运行区显示回答尾部、最多三个工具的最新进度、
轮次、耗时及 token。运行完成、取消、失败或达到轮次上限时会留下结果；`tokens+` 表示有一轮
未报告用量。长的单行回答会显示最新文字，长路径保留末尾文件名和工具进度；窄窗口优先
显示运行状态与停止快捷键。普通按键在运行中被丢弃，不回显，也不排队发送为下一条问题。
当前使用单行输入：一个输入批次中的首个换行会提交问题，后续内容被丢弃。请等待提示符
重新出现再发送下一条；粘贴多行文本不会作为完整的多行问题保留。

切换供应商不会清空当前对话。新供应商没有默认模型时，用 `/model MODEL` 设置；
自定义 OpenAI 兼容端点还需 `/endpoint URL`。TUI 在选择缺 Key 的供应商后会立即询问 Key，
可先保存 Key，再补模型和地址；已有 Key 则跳过。`/login` 用于之后更换 Key。
`--api-key` 只用于启动时选择的供应商，不会误用到之后切换的供应商。
Key 写入用户的 `auth.json`，不同供应商各用自己的条目。
从 OpenAI 在会话内切换到自定义兼容端点时，也不会把 `OPENAI_API_KEY` 当作新端点的 Key；
切换到该端点时会单独询问它的 Key。

TUI 保留正常屏幕与终端原生滚动历史。提示符、进度和结果摘要写入 stderr，最终回答写入
stdout，支持 `node dist/cli.js --tui > answers.txt`。非 TTY 或非交互式调用仍明确拒绝
`--tui`；默认 CLI 和 JSON 模式继续使用原有渲染器。

## 终端适配

使用 `string-width` 与 `Intl.Segmenter` 按显示列和完整字符簇截断中文、组合字符及 Emoji。
运行区预留末列以避免自动换行；矮窗口优先保留状态。缩放时根据旧内容重排后的行数清除
原区域，再重画；清理范围限制在当前可见高度，避免极矮窗口把新状态滚出屏幕。
不同终端对 Emoji 宽度和历史重排的实现仍可能存在差异。

输入由 readline 编辑，先独立解码按键，使粘贴与逐字输入使用相同的编辑路径，保持折行和
插入位置正确。TUI 输入适配层收到首个换行就关闭接收，直到 REPL 准备好下一行，避免
异步迭代器提前缓存后续问题；运行中仅转发 Ctrl+C。原始 stdin 不暂停，因此取消不会
被吞掉。退出或异常时会移除输入监听并恢复终端模式。运行环境要求 Node.js 22 或更新版本。

## 验证

```sh
npm run check
TMPDIR=/private/tmp npm test  # macOS 使用短路径，远程测试需要本地 socket 权限
npm run build
npm run demo:tui
```

自动测试覆盖显示列宽、字符簇、控制字符、欢迎面板、命令补全、输入隔离、取消后继续提问、
退出恢复、输出分流、失败提示和缩放清除旧行。`tests/tui-screen.test.ts` 使用 xterm 终端
解析器检查执行控制码后的屏幕内容，覆盖长中文粘贴、光标中间插入、草稿取消、EOF 清理、
快速多行提交，以及 80×24→32×12 / 16×5→120×40 缩放并保留历史。
真实 PTY 另验证 80→32→80 列缩放、流式工具、
Ctrl+C、再次提问、会话命令、Ctrl+D 和重定向 stdout。
